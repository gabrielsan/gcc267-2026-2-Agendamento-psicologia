## Review Focus
- Sessão de usuário desativado deve encerrar acesso.
- Professor não pode editar consulta alheia ou enviar campos de horário.
- Erros preservam formulário sem expor senha.
- Filtros/paginação inválidos não geram erro 500.
- Login por sessão não deve tornar a API vulnerável a mutações sem CSRF.
